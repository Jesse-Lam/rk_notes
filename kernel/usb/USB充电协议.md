# USB 充电协议

## 常见的 USB 充电协议

随着移动设备的普及和人们对快充的需求日益增长，USB 充电技术也经历了快速发展。不同的设备和品牌使用不同的充电协议，导致了市场上充电器、数据线和移动设备之间的兼容性成为重要的考量因素。这里将分享一些常见的 USB 充电协议，帮助大家更好地理解它们的差异。

### 1. **USB 2.0/3.0 标准充电协议**

最早的 USB 充电协议是伴随数据传输功能一起设计的。在 USB 2.0 标准下，充电电流最大为 **500mA (2.5W)**，而 USB 3.0 协议将电流上限提升到了 **900mA (4.5W)**。虽然这些协议支持基础的充电需求，但由于功率较低，充电速度非常缓慢，因此适合用于 U 盘、鼠标、键盘等低功耗设备的供电和充电。

### 2. **USB BC 1.2（Battery Charging Specification）**

为了提高 USB 端口的充电能力，USB 协会（USB-IF） 在 2010 年推出了 **Battery Charging Specification 1.2** 协议。该协议定义了三种端口类型：

- **标准下行端口(SDP)**：主要用于数据传输，最大支持 **500mA** 电流。
- **充电下行端口(CDP)**：在数据传输的同时，提供更高的充电电流，最大支持 **1.5A** 电流。
- **专用充电端口(DCP)**：仅用于充电，不支持数据传输，最大支持 **1.5A** 电流。

这是早期手机和其他移动设备常用的充电方案。

### 3. **USB Power Delivery (PD)**

**USB Power Delivery (PD)** 是目前最主流的 USB 充电协议，支持高达 **240W** 的功率传输。USB PD 协议通过灵活的电压和电流调整，使得设备可以选择最适合的充电参数。这意味着 USB PD 不仅可以为手机充电，还可以为笔记本电脑、显示器等大功率设备提供电力。

USB PD 的优势在于其**双向充电**能力，即设备可以既作为充电器又可以作为被充电设备。同时，USB PD 兼容性好，越来越多的设备和品牌开始支持此协议，使其成为快充领域的标准。

### 4. 高通 **Quick Charge (QC)**

**Quick Charge (QC)** 是由高通推出的一种快充协议，通常用于搭载高通芯片的智能手机。QC 通过动态调整电压和电流，在手机不发热的前提下大幅提升充电效率。不同版本的 QC 支持不同的功率输出：

- **QC 2.0**：支持 5V、9V、12V 和 20V 输出，功率最高可达 **18W**。
- **QC 3.0**：采用“智能调节”，根据设备电池的充电状态动态选择电压，支持最高 **18W**。
- **QC 4.0/4.0+**：最高支持 **100W**，并且兼容 USB PD 协议，使其具备更广泛的应用场景。

### 5. **OPPO VOOC**

**VOOC（Voltage Open Loop Multi-step Constant-Current Charging）** 是 OPPO 推出的专有快充协议，采用**低压大电流**的充电模式。与大多数协议通过提高电压实现快充不同，VOOC 采用 **5V** 低电压并增加电流至 **4A** 或更高，从而减小充电过程中产生的热量。最新的 SuperVOOC 充电功率可达到 **65W**，大幅缩短充电时间。

### 6. 华为 **SuperCharge**

华为的 **SuperCharge** 快充协议通过 **低电压高电流** 的方式，提升了充电效率，最新版本可支持高达 **100W** 的功率输出。该协议使用分层控制技术，保证在大功率充电时仍能维持低温，避免因过热引发的充电效率下降。

### 7. 三星 **Adaptive Fast Charging (AFC)**

**Adaptive Fast Charging (AFC)** 是三星的快充协议，支持在 **5V/2A** 或 **9V/1.67A** 的条件下为设备快速充电。三星的 AFC 协议与 高通 QC 协议兼容，使其在支持的三星设备上能够提供类似的快充体验。

### 8. **MTK Pump Express (PE)**

MTK 推出的 **Pump Express** 快充协议是另一种市面上较为常见的快充技术，通常用于搭载 MTK 芯片的设备。Pump Express 支持动态电压调节，并且在某些情况下可兼容 USB PD 协议，最新版本支持最高 **100W** 的充电功率。

### 9. **Apple 2.4A 快充**

Apple 2.4A 快充协议是苹果早期推出的快充技术，支持最高 **12W**（5V/2.4A）的充电功率。使用Apple 2.4A 快充协议时，需要搭配支持该协议的充电头和 USB-A 转 Lightning 的数据线，虽然功率不算高，但在苹果的生态系统中已经提供了不错的充电效率。

## RK 平台支持的 USB 充电协议

RK 平台在支持 USB 充电协议方面，主要包含对主流充电协议的支持，包括：

**BC 1.2**：RK 平台几乎所有的 SOC 芯片都支持 BC 1.2 协议，可以识别接入的 USB 是 SDP，CDP，DCP，并根据接入的充电器类型调整充电功率，主要实现模块在 USB PHY 驱动中。

**PD**：支持 USB TYPE-C 口的主控，如：RK3399，RK3588，RK3576等，SDK 默认配置就已经支持 PD 协议（硬件需要加 PD 协议芯片，如：FUSB302，HUSB311等），其他主控加了 PD 协议芯片之后也可以支持 PD 协议。

## 结语

随着移动设备对充电速度的需求不断增加，USB 充电协议经历了快速的迭代和发展。不同的协议适用于不同的设备和使用场景，对于用户来说，了解这些协议有助于选择合适的充电设备，对于嵌入式开发者来说，了解这些协议，有助于对硬件产品的理解和开发。
